# PimsOS Builder — Checklist de synchronisation dépôt

## Avant séance

- [ ] Lire la note `DocumentationSync-*` la plus récente.
- [ ] Lire `ProjectStatus.md`.
- [ ] Lire `CurrentSprint.md`.
- [ ] Vérifier `git status`.
- [ ] Vérifier `git log --oneline -5`.
- [ ] Vérifier le dernier état GitHub si la connexion est disponible.
- [ ] Vérifier les derniers tests et les outils ajoutés.
- [ ] Lancer l'inventaire Diagnostics adapté.

## Avant modification

- [ ] Preuve du problème obtenue.
- [ ] Cause distinguée de l'hypothèse.
- [ ] Code réel consulté.
- [ ] Tests existants consultés.
- [ ] ADR/architecture consultés si nécessaire.

## Avant Build réel

- [ ] Diagnostic terminé.
- [ ] Aucun `UNKNOWN` pertinent ignoré sans justification.
- [ ] Build explicitement autorisé.
- [ ] Environnement et Workspace vérifiés.
- [ ] ISO source disponible.

## Fin de séance

- [ ] Tests exécutés et résultats notés.
- [ ] Documentation synchronisée.
- [ ] Changelog mis à jour si nécessaire.
- [ ] Git status compris.
- [ ] Commit cohérent prévu/realise.
- [ ] Note `DocumentationSync-*` mise à jour si l'état de référence change.
